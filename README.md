# Denizli PPF

[denizlippf.com](https://denizlippf.com) için tek sayfalık site. Odak: **Denizli göçük** ve **Denizli PPF** aramaları.

## İletişim bilgilerini doldur

`src/data/site.ts` içinde telefon, WhatsApp, adres, e-posta ve Instagram’ı gerçek değerlerle değiştir.

WhatsApp numarası uluslararası formatta, başında `+` olmadan: `90555xxxxxxx`.

## Çalıştır

```bash
npm install
npm run dev
```

## Yayınla

Vercel’e bağla, domain olarak `denizlippf.com` ekle. Google Search Console + Google İşletme Profili (Denizli göçük / PPF) sıralama için siteden daha kritik.
